# 30-minute RTX 5060 soak — 2026-10-20

## Result

The integrated nano-vLLM candidate completed the full 30-minute measurement window without failed calls or scheduler preemptions. It generated 2,296,064 completion tokens across 8,969 successful calls. Whole-window throughput was **1,275.48 tok/s**. The 30 complete per-minute buckets ranged from **1,271.47 to 1,284.27 tok/s** (about a 1.0% spread); the final 0.16-second partial bucket is excluded from that range.

| Measure | Result |
|---|---:|
| Successful / failed calls | 8,969 / 0 |
| Scheduler preemptions | 0 |
| Completion tokens | 2,296,064 |
| Measured window | 1,800.16 s |
| Whole-window throughput | 1,275.48 tok/s |
| Full-minute throughput range | 1,271.47–1,284.27 tok/s |
| Peak PyTorch allocated / reserved | 4.80 / 4.88 GiB |
| GPU board power, median / mean | 102.64 / 102.25 W |
| GPU temperature, median / maximum | 60 / 66 °C |
| Graphics clock, median / range | 2,722 MHz / 2,512–2,737 MHz |
| Memory clock | 13,801 MHz throughout |
| GPU utilization, median / mean | 85 / 84.78% |

No active clock-throttle reason was reported in spot checks during the run. Temperature, clock and power values are the laptop GPU's `nvidia-smi` telemetry, not whole-device wall-power readings.

## Energy estimate

Power was sampled about once per second and integrated with the trapezoidal rule over 1,799.53 seconds of telemetry coverage (1,798 samples).

| Measure | Result |
|---|---:|
| Gross GPU board energy | 184,027 J (51.12 Wh) |
| Pre-run idle median | 24.745 W |
| Idle-adjusted GPU energy estimate | 139,498 J (38.75 Wh) |
| Gross GPU board tokens/J | 12.48 |
| Idle-adjusted GPU board tokens/J estimate | 16.46 |

Idle-adjusted energy subtracts the pre-run idle median from the measured board energy. It is an estimate and excludes laptop CPU, memory, display, fans outside the GPU telemetry, and AC/DC losses. Do not present it as whole-laptop energy efficiency.

## Test configuration

- Tested source commit: `11d0aa58a2c68d7132dd0d919e1029afea6a6aa2`.
- RTX 5060 Laptop, SM120, 8 GiB; WSL2; PyTorch 2.14.1+cu130; CUDA Runtime 13.0; Python 3.12.3.
- Qwen3-0.6B revision `c1899de289a04d12100db370d81485cdf75e47ca`, BF16.
- FlashInfer attention, SM120 RMSNorm, Torch Q/K Norm + RoPE, 16-token KV pages, CUDA Graph enabled.
- Batch 8, alternating synthetic token-ID prompts of 64 and 256 tokens, 32 output tokens, temperature 0.6, EOS ignored; three warmups per case.

This is a fixed synthetic-token soak. It measures repeatability and GPU-board energy for these two shapes; it is not a diverse online-user traffic trace or a service-level latency test.
